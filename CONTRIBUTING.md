# Guía de Contribución

## ¿Cómo puedo contribuir?

### Reportar errores
- Usa el sistema de Issues de GitHub
- Describe el error con pasos para reproducirlo
- Incluye capturas de pantalla si es posible

### Sugerir mejoras
- Abre un Issue con la etiqueta "enhancement"
- Describe la mejora y por qué sería valiosa

### Contribuir con código
1. Forkea el repositorio
2. Crea una rama con nombre descriptivo
3. Sigue los estándares de código (TypeScript, ESLint)
4. Haz commit con mensajes claros
5. Abre un Pull Request

### Contribuir con contenido
- Añadir nuevas entidades a `lib/data/entities.ts`
- Mejorar las descripciones de arquetipos
- Añadir fuentes a la Biblioteca Pública

## Estándares de Código

- TypeScript estricto
- Componentes funcionales con hooks
- Tailwind para estilos
- Documentación en español
