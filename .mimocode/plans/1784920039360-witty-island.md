### 5.2 Opciones para Fase 4

| Opción | Descripción | Impacto | Esfuerzo |
|---|---|---|---|
| **A) SEO + contenido indexable** | Agregar metadata a ~20 páginas, mejorar sitemap, crear contenido educativo indexable | Alto (tráfico orgánico) | Medio |
| **B) Viralidad y sharing** | Mejorar ShareableImageCard, agregar sharing contextual en más momentos, deep links más precisos | Alto (crecimiento) | Medio |
| **C) Retención / Daily Insights** | Mejorar "Hoy en Molino", agregar recordatorios, mejorar el loop de retorno diario | Alto (retención) | Medio |
| **D) Base de conocimiento** | Agregar más entidades, más contenido educativo, más relaciones | Medio (contenido) | Alto |

### 5.3 Recomendación: Opción A — SEO + Contenido Indexable

**Justificación:**

1. Molino ya tiene una base sólida de funcionalidad (onboarding, profile, sharing, entities)
2. El SEO es el canal de crecimiento con mayor ROI para una app sin presupuesto de marketing
3. Las ~30 páginas sin metadata representan contenido que Google no puede indexar correctamente
4. Las 12 páginas de `/conocimiento/zodiaco-chino/[animal]` son contenido educativo de alta calidad que ya existe pero no tiene metadata
5. El sitemap ya incluye muchas rutas, pero sin metadata dinámica los previews de sharing son genéricos
6. Una vez que el SEO esté sólido, el tráfico orgánico alimenta el viral loop (usuarios descubren → comparten → más tráfico)

**Orden recomendado para Fase 4:**
1. Sprint 5 (este): Consolidación de datos + SEO metadata
2. Sprint 6: SEO metadata dinámica para contenido educativo
3. Sprint 7: Sharing viral (mejores CTAs, deep links más precisos)
4. Sprint 8: Retención (mejoras a Daily Insights)
